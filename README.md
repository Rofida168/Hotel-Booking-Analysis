# Hotel Booking Analysis

## Overview

A Power BI project focused on analyzing hotel booking data and exploring booking and cancellation trends.

## Tools

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Objectives

- Clean and transform booking data using Power Query.
- Analyze booking and cancellation trends.
- Create DAX measures to track key performance indicators (KPIs).
- Develop an interactive dashboard to present insights.
